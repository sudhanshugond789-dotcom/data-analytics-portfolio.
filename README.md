# HR Employee Attrition Analysis
**Goal:** Examine employee attrition by department, overtime, tenure, satisfaction, and income.
**Tools:** Python, Pandas, Matplotlib, Excel, SQL (SQLite).
**Data:** Synthetic practice data; attrition=1 means left, 0 means retained.
## Run
`pip install -r requirements.txt` then `python analysis.py`
Import CSV as `hr_employee_data` for `queries.sql`.
## Outputs
Excel report and department attrition chart. Do not use synthetic results for real employment decisions.
